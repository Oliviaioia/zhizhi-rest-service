# 知止 旅途休憩小程序

依据《小程序0929.docx》完善的可运行本地 MVP。原文档未改动。包含原生微信小程序和浏览器预览，共用业务规则，无安装依赖。

## 立即体验

在项目目录运行 `npm start`，打开 http://127.0.0.1:4173 。

微信开发者工具：导入本项目根目录，读取 `project.config.json`，选择测试号或替换为自己的 AppID。源码在 `miniprogram`，无需 npm 构建。当前 `touristappid` 用于无 AppID 本地调试，不代表已注册或发布。

## 已实现

- 休憩首页：深海蓝主色、香槟金点缀；全旅程陪伴、四类快捷服务、示例站点资源、实时舒适度、分人群关怀与夜间关怀。
- 服务中心：洗衣代取送、安心叫醒、餐食预留、轮胎检测、无障碍协助、婴儿车借用；支持服务登记、线上取号、取消号码和预计等候。
- 安心守护：车辆异动守护、儿童防走失提醒的交互演示；明确未连接真实监控、蓝牙或定位设备。
- 基础预约：未来7天时间校验、授权确认、重复拦截、家人代预约、六位预约码、取消、跨站改签、演示核销。
- 空间地图：设施说明、无障碍示意路径、微信扫码识位、手工位置码、离线资料保存。
- 碳账单：已完成预约产生估算减排；自带水杯、光盘行动、绿电休息、步行舒展支持每日打卡积分；含余额校验与兑换记录。
- 数据小账本：汇总本地预约、服务、排队、反馈和位置采集情况，支持无痕模式与全部本地数据删除。
- 运营看板：本地预约统计、排队队列、服务准备进度、反馈接单与解决；浏览器另含示例客流图和报告导出。
- 扩展：示例行程匹配、路线收藏、手动驾驶计时、家庭代约、大字模式、夜间模式、无痕和本地数据删除。

## 演示路径

1. 首页选择睡眠舱，选择未来时间，勾选数据保存授权，确认预约。
2. 我的旅程查看预约码，测试跨站改签、取消或演示核销。
3. 核销后进入碳账户，查看估算减排和积分并兑换。
4. 地图输入 `ZZ:s1:family`，或用微信扫描包含此文本的二维码。
5. 提交“淋浴间热水无法使用”反馈，在运营看板接单、解决，再回到我的反馈检查状态。

## 边界与后续接入

这是一套离线本地演示实现，不是已上线的平台。没有支付、真实预约、短信、订阅推送或值班人员呼叫。站点、余量、时间距离、环境、预测均为固定示例；路线输入用于展示方案，不进行真实地图搜索。示意图不提供定位、蓝牙信标、室内精确导航或可靠安全指引。

浏览器与微信端各自保存本地数据，不互相同步。页面中的运营入口是演示入口，没有生产管理权限；上线前必须接入服务端身份认证与权限控制。扫码仅解析预设位置码，不访问外部链接。预约码是演示查询码，无签名和服务端校验，不可用于真实门禁。多用户容量、并发锁、幂等支付与服务端核销尚未接入，客户端存储不应作为生产订单系统。

碳账单每次用电固定1.2 kWh，电力因子0.5306 kg CO₂/kWh作为场景参数；减排按绿电替代估算，未验证时间与地区适用性，不包含Scope 1/3、水、食物、商品、生命周期排放。不代表核证减排、绿证或CCER资产。

本地数据包括设施、时间、预约码、反馈、评价、收藏和积分，保留至删除。未采集手机号或定位。无痕模式清除持久存储并仅在本次会话保留；关闭无痕会重新保存当前会话数据。未承诺清除操作系统或浏览器自身日志。微信小程序已加载后可查看本地地图和预约；浏览器必须保持页面打开，不支持关闭页面后离线重新载入。

文档 V2/V3 的真实AI预测、AI节能控制、设备监控、儿童防走失、语音操作、多平台及车机/物流接入尚未实现。上述功能需要硬件、数据接口、账号与现场验证，不能由本地演示替代。微信完整读屏和低版本兼容需在目标真机验收。

## 上线所需

提供微信 AppID、合法服务域名与部署环境；实现服务端用户身份与管理员鉴权、订单和库存事务、核销令牌、设备/地图接口、消息订阅与数据删除规则。将共享业务层替换为调用服务端的适配器，保留客户端展示校验。所有生产价格、碳因子与现场状态需由可信来源配置。

## 验证

`npm test` 验证预约、改签、核销、积分、工单、核算与恢复边界；`npm run check` 验证JS语法、JSON配置与两端共享规则一致。微信开发者工具编译、摄像头、真机读屏和平台发布审核需在对应环境完成。
